# Solo reflection icon assets

Generated with the built-in `image_gen__imagegen` tool. The four PNGs in `reference/` were used as local visual references for palette, silhouette language, scale, and transparent padding. The two generated implementation assets are copied to `dist/assets/completion/` and are also mirrored beside this record for design review.

## 自分にひとこと

```text
Use case: ui-mockup
Asset type: standalone transparent UI icon asset
Input images: Image 1: existing overlapping cobalt speech bubbles for the shared icon style; Image 2: existing coral heart for palette; Images 3-4: existing applause and bookmark for scale and silhouette language.
Primary request: Generate one centered single warm coral speech bubble icon representing “自分にひとこと”. It should suggest voice and saying one's own words, but contain no pencil, no quotation marks, no letters, no face, and no person.
Style/medium: clean flat filled product UI icon, same soft polished Mingle.cards language as the references, simple rounded silhouette with a small tail.
Composition/framing: one icon only, centered and large on a square transparent canvas, matching the reference icon scale and padding; clearly recognizable at 80px.
Color palette: warm coral with a small deep-navy secondary accent only if needed; no rainbow.
Constraints: genuinely transparent background, no card, no border, no label, no text, no face, no human figure, no gradient, no shadow, no sparkle, no glow, no watermark.
```

Output: `dist/assets/completion/completion-self-note.png`

## 小さな一歩

```text
Use case: ui-mockup
Asset type: standalone transparent UI icon asset
Input images: Image 1: existing overlapping cobalt speech bubbles; Image 2: existing coral heart; Images 3-4: existing applause and bookmark for scale and silhouette language.
Primary request: Generate one centered two-step footprint symbol representing “小さな一歩”: two simple soft rounded footprint-like marks stepping upward and to the right, stylized abstract symbols rather than realistic anatomy.
Style/medium: clean flat filled product UI icon, same soft polished Mingle.cards language as the references, simple rounded silhouette.
Composition/framing: one icon only, centered and large on a square transparent canvas, matching the reference icon scale and padding; clearly recognizable at 80px.
Color palette: cobalt and deep navy, with a restrained small coral or ochre accent only if needed; no rainbow.
Constraints: genuinely transparent background, no realistic feet, no person, no legs, no shoe details, no card, no border, no label, no text, no gradient, no shadow, no sparkle, no glow, no watermark.
```

Output: `dist/assets/completion/completion-small-step.png`
