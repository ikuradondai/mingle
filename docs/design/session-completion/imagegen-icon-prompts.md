# Mingle.cards completion icon prompts

All four icons were generated with the built-in `image_gen` tool using `mingle-completion-ui-design-board.png` as a style reference. Each request asked for a single centered transparent PNG with no card, label, text, gradient, shadow, or watermark.

## 共通点 — `completion-common-pair.png`

```text
Use case: ui-mockup
Asset type: standalone transparent UI icon asset
Input images: Image 1: reference board; match the blue overlapping speech-bubble icon shown on the left desktop panel
Primary request: Generate one centered icon only: two overlapping blue speech bubbles representing 共通点, with the front bubble slightly darker cobalt blue and the rear bubble a lighter cobalt blue.
Style/medium: flat filled product UI icon, clean mature Mingle.cards style, crisp smooth silhouette.
Composition/framing: one icon centered, occupying most of the square canvas with generous transparent padding.
Color palette: cobalt blue pair matching the reference board.
Constraints: transparent background, no frame, no card, no label, no Japanese text, no logo, no gradient, no shadow, no extra objects, no watermark.
```
