# テーマへのいいね

6枚ごとの振り返り画面で、実際に遊んだ公式テーマに任意で1回だけ「いいね」を送信できます。テーマミックスでは、そのラウンドに含まれた公式テーマごとに評価できます。マイセット、共有セット、店舗セッションなど、利用者が作成・共有した内容は対象外です。

送信するのは公式テーマID、ブラウザで生成した氏名や回答を含まないランダムな識別子、重複排除用のイベントIDだけです。識別子と投票済みテーマは、利用者がブラウザの保存データを削除するまで端末のローカル領域に保持します。サーバー側ではハッシュ化した識別子とテーマの組み合わせを90日間の重複排除に使います。厳密な本人確認ではなく、ブラウザ削除や端末変更などでは重複を完全には防げません。

送信に失敗した場合は票を保存せず、画面から再試行できます。いいねは取り消しできません。続ける操作やプレイ終了は、評価しなくても利用できます。
