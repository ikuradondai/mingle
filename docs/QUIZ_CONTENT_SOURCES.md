# 一般クイズの根拠

48問は自作の短文で、時事・医療・法律・価格など変動しやすい題材を避けています。初級・中級は一般的な教科知識と計算、上級・特級の専門的な事実は一次資料で確認しました。計算問題は式をコードレビューで検算しています。

## 上級

- `advanced-02`: [NIST 元素周期表](https://www.nist.gov/pml/periodic-table-elements) — Wはタングステン。
- `advanced-03`: [国立天文台「標準時」](https://eco2.mtk.nao.ac.jp/koyomi/wiki/C9B8BDE0BBFE.html) — 日本標準時の標準子午線は東経135度。
- `advanced-04`: [国土交通省「琵琶湖及び集水域」](https://www.mlit.go.jp/kokudoseisaku/content/001514385.pdf) — 琵琶湖は日本最大の淡水湖。
- `advanced-05`: [国立公文書館「五箇条の御誓文が発せられる」](https://www.archives.go.jp/ayumi/kobetsu/m01_1868_02.html) — 1868年3月14日。
- `advanced-06`: [国立国会図書館典拠「富嶽三十六景」](https://id.ndl.go.jp/auth/ndlna/001205236) — 創作者は葛飾北斎。
- `advanced-07`: [環境省「オゾン層に関する基礎情報」](https://www.env.go.jp/earth/report/h25-04/full.pdf) — オゾンの大部分は成層圏にある。
- `advanced-08`: [国立天文台「どの年がうるう年になるの？」](https://www.nao.ac.jp/faq/a0306.html) — グレゴリオ暦の400年は97閏年。
- `advanced-09`: [国土交通省「日本の主な川」](https://www.mlit.go.jp/river/toukei_chousa/kasen/jiten/nihon_kawa/) — 信濃川は日本最長の川。
- `advanced-11`: [国立国会図書館「風姿花伝」](https://ndlsearch.ndl.go.jp/books/R100000002-I000007628878) — 「風姿花伝」は世阿弥の能楽論。
- `advanced-12`: [国立公文書館「大政奉還」](https://www.archives.go.jp/exhibition/digital/henbou/contents/01.html) — 大政奉還は1867年。
- `advanced-01`, `advanced-10`: 2の累乗とフィボナッチ型数列を式で検算。
