# Mingle.Cards 会話カード試作

## 起動

```powershell
cd C:\dev\carding\site
npm start
```

ブラウザで `http://127.0.0.1:5180` を開きます。サーバーは `dist` だけを配信し、パストラバーサルを拒否します。`PORT` 環境変数で別ポートを指定できます。

## 設計

- `dist/data/decks.js`: 38デッキ×40問のデータ。通常34デッキと成人向け4デッキを収録し、dateは通常40問にintimacyのR18追加候補を混ぜられます。初対面6テーマ、なりきり9テーマ、お見合い、スポーツのチームメート向けデッキも含みます。
- `dist/engine.js`: 通常40枚、または通常34枚＋R18 6枚の構成を重複なしで生成し、6枚区切り、戻る、参加者ローテーションを管理。
- テーマ選択で「やってみて」を有効にすると、`dist/data/challenges.js` の一般20お題から6枚を抽選し、各6枚区切りに1枚ずつ入れます。カード総数は40枚のままです。軽いボディタッチを含む9お題は、カップル向け6デッキで2名参加のときだけ候補になります。いずれも任意で、R18には分類しません。
- `dist/access-policy.js`: 続行可否の非同期境界。現在は常に許可し、将来はサーバーで検証済みの課金権限に差し替える。
- `dist/app.js`: 参加者、テーマ、R18追加同意、カード進行のUI。呼び名・進行・いいね数だけを端末に保存し、回答内容は保存しない。
- 各6枚の区切り（最後は4枚）で、任意の評価と1000文字までのフィードバックを送信できます。送信したフィードバックは管理画面で確認でき、評価・本文のどちらか一方だけでも送信できます。送信中に画面を移動しても別セッションへ混入しません。
- WebMCPは`document.modelContext.registerTool`が利用できるブラウザでのみ登録し、ページ離脱時にAbortControllerで解除します。未対応ブラウザでは通常のUIがそのまま動きます。

## 現在の制限

購入・決済、店舗コード、回答の保存は未実装です。任意のSupabaseアカウント機能（GoogleまたはメールOTP、質問のお気に入り、マイセット）は [docs/ACCOUNT_SETUP.md](docs/ACCOUNT_SETUP.md) の設定後に有効になります。設定がない場合はゲストプレイを継続します。R18のテーマや追加質問は全員18歳以上かつ話題への明示同意が必要です。続行権限を有料化する場合、ブラウザのフラグだけで許可せず、サーバー側で購入状態を検証してください。

参加者名と進行状態は、進行中のゲームについて端末内に24時間保存されます。トップ画面から明示的に再開でき、ページ更新後も質問、話者、いいね数を復元します。参加者は2〜8名です。WebMCPの実ブラウザ動作は未検証で、通常UIとengineのNodeテストを検証対象にしています。

## 管理画面と利用統計

`/admin` は `ADMIN_PASSWORD` でログインする管理画面です。パスワードと `ADMIN_SESSION_SECRET` はサーバー環境変数だけで設定し、ブラウザや静的ファイルには埋め込みません。管理セッションは短期の署名済みHttpOnly cookieで、統計APIは認証済みセッションだけが利用できます。

統計は個人情報を保存せず、許可済みの画面ID・テーマID・JST日付だけを共有Redisへ保存します。PVは画面遷移につき1回、テーマ開始数は正常にセッションを作成できた回数です。再描画、テーマのradio選び直し、同じeventの通信retryは増分しません。管理画面の操作と無効イベントは集計対象外です。表示期間は今日、過去7日、過去30日、累計で、累計は計測開始時点からの値です。

本番の永続化には `UPSTASH_REDIS_REST_URL` と `UPSTASH_REDIS_REST_TOKEN` を設定します。Vercel KV接続で提供される `KV_REST_API_URL` / `KV_REST_API_TOKEN` も互換fallbackとして利用できます。`ADMIN_PASSWORD` と `ADMIN_SESSION_SECRET` は必須で、代替値やfallbackはありません。永続storeまたは認証秘密がない本番環境は503で停止します。

開発環境は `ANALYTICS_NAMESPACE=development` など、productionと異なるnamespaceを必ず使ってください。明示的に `ANALYTICS_LOCAL_STORE=1` を設定した場合だけ `.data/analytics.json` をローカル保存先にします。テストは一時ディレクトリを使い、実Redisや開発集計へ書き込みません。`.env.local` はGit管理外です。
### テーマミックスと途中再開

通常テーマを2〜3個選ぶ「テーマミックス」と、恋愛・夫婦、友人、家族、仕事、スポーツ、初対面、なりきり、R18のテーマ絞り込みに対応しています。R18テーマは単独モードと成人同意が必要です。ミックスにはR18カードを含めません。

進行中のセッションは現在のブラウザに24時間だけ保存され、トップ画面の「前回の続き」から明示的に再開できます。呼び名・カードの順番・回答者・進行・いいねを保存します。回答内容は保存しません。40枚完了または削除で破棄します。保存できない環境でも通常のプレイは続けられます。

送信済みのフィードバックの区切り位置だけは同じセッションの再開用に端末へ保存します。フィードバック本文と評価は端末保存に含めません。サーバー送信にも呼び名・質問文・回答内容を含めず、回答内容の録音入力もありません。送信したフィードバックはサーバーに保存され、管理画面から確認できます。

進行分析ではテーマ開始に加えて、カード進行のセッション単位イベントを記録します。再開時にはテーマ開始イベントを重複送信しません。

区切り画面では、保存済みの回答者別いいねをカード範囲ごとに集計します。フィードバックの評価は集計に含めません。
