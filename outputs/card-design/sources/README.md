Text, logo, and questions are intentionally omitted from generated art; production HTML overlays real text and the official `/assets/mingle-cards-masthead.png`.

- family.png: home/tree/sun and warm connected line; coral/gold/navy.
- work.png: compass, path, horizon and forest; teal/navy/gold.
- sports.png: energetic abstract balls, court and finish-line marks; cobalt/coral/lemon.

The first six sources were previously generated and approved; they were copied without regeneration. The last three were generated as separate built-in calls on 2026-10-06.
